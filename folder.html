Production Website Folder Structure

What big companies use — HTML / CSS / JS project

my-website/ ROOT ← open this in VS Code
assets/ FOLDER ← original source files, never deployed directly
images/ ← original full-res images (JPG, PNG, SVG)
fonts/ ← .woff2 font files, self-hosted
icons/ ← SVG icons
videos/ ← original video files
css/ FOLDER ← split by purpose, one file = one job
variables.css ← all colors, sizes, spacing as CSS variables
base.css ← browser resets, same look in all browsers
layout.css ← header, footer, grid, containers
components.css ← buttons, cards, modals, badges
utilities.css ← helper classes like .hidden, .flex, .mt-16
animations.css ← all @keyframes and transitions
main.css ENTRY ← imports all CSS files. HTML links only to this
js/ FOLDER ← split by purpose
utils.js ← helper functions: formatDate, validateEmail
components.js ← UI logic: nav, modal, tabs, accordion
api.js ← all fetch/API calls in one place
animations.js ← scroll animations, intersection observer
main.js ENTRY ← imports everything, runs on page load
pages/ FOLDER ← each page = its own folder (clean URLs)
about/ ← yoursite.com/about/
index.html
contact/ ← yoursite.com/contact/
index.html
blog/ ← yoursite.com/blog/
index.html
public/ SEO + BROWSER ← served as-is, no processing
favicon.ico ← browser tab icon
favicon-512.png ← for Android/iPhone home screen
robots.txt SEO ← tells Google what to crawl
sitemap.xml SEO ← map of all pages for Google
manifest.json ← PWA: makes site installable as app
og-image.jpg ← 1200x630px image for social sharing
dist/ AUTO-GENERATED ← never edit! build tool creates this
main.min.css ← minified (40KB → 8KB)
main.min.js ← minified (60KB → 12KB)
images/ ← compressed WebP images (4MB → 80KB)
index.html HOMEPAGE ← yoursite.com → server reads this first
404.html ← custom page not found screen
.env SECRET ← API keys, passwords. NEVER commit to Git
.gitignore ← tells Git: ignore node_modules, dist, .env
.htaccess ← server rules: redirects, caching, HTTPS force
package.json ← project config + build scripts (npm run build)
README.md ← project docs: how to run and deploy
